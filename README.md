# SafeSystem

>[!Warning]
>**Proyecto Privado**
>
>Este sistema está desarrollado exclusivamente para uso interno de Safe Seguridad.

Sistema interno desarrollado para la gestión comercial, técnica y operativa de Safe Seguridad.

El objetivo principal del proyecto es centralizar la información de clientes, instalaciones y dispositivos de seguridad en una única plataforma, permitiendo optimizar la gestión diaria de la empresa, mejorar la precisión de los presupuestos y reducir errores operativos.

# 📌 Descripción General

El sistema estará dividido en dos grandes módulos principales:

## 🔹 CRM de Clientes e Instalaciones

Este módulo permitirá gestionar toda la información relacionada con los clientes y sus sistemas instalados.

### Funcionalidades principales
- Gestión de clientes
- Información de contacto
- Direcciones e instalaciones
- Registro de dispositivos instalados
- Configuraciones técnicas
- Historial de instalaciones y mantenimiento
- Observaciones técnicas y comerciales

### Objetivo

Centralizar la información operativa y técnica de cada cliente para facilitar:

- soporte técnico
- mantenimiento
- ampliaciones
- seguimiento comercial
- futuras instalaciones

## 🔹 Catálogo Inteligente de Dispositivos

Este módulo funcionará como una base de datos estructurada de dispositivos de seguridad y suministros.

### Categorías iniciales
- Cámaras analógicas
- Cámaras IP/WiFi
- DVR / NVR
- Alarmas
- Controles de acceso
- Ficheros
- Fuentes
- Redes
- Accesorios
- Cableado
- Información almacenada

Cada dispositivo podrá contener:

- Marca
- Modelo
- Tipo
- Características técnicas
- Compatibilidades
- Alcances
- Observaciones
- Costos
- Stock (opcional a futuro)


### 🎯 Objetivo del Sistema

El sistema busca mejorar el proceso de armado de presupuestos técnicos permitiendo:

- Seleccionar dispositivos adecuados según las necesidades reales del cliente
- Evitar sobrecostos por equipos innecesarios
- Evitar faltantes de materiales
- Estandarizar instalaciones
- Reducir errores humanos
- Optimizar tiempos de planificación
